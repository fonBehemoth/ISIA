# ISIA

Adaptive real estate homepage based on the supplied design. Ukrainian (default), English and Russian; remembered language selection; automatic crossfade slideshow with arrows and pause; five-image gallery with keyboard navigation; demo contact form (no data sent or saved).

Open `index.html` directly or serve this directory with a static HTTP server. No build step or dependencies are required.

GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).

The gallery images illustrate destinations; captions are descriptive and do not represent verified property listings. No prices are published. The 170+ figure follows the supplied mockup and should be confirmed before production use.
